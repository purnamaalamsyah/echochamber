# 🏛️ Political-RAG Indonesia

Sistem Analisis Cerdas untuk Ekstraksi Informasi Politik dari Media Indonesia menggunakan Retrieval-Augmented Generation (RAG) dan Generative AI.

## Fitur

- 📄 Multi-format support (CSV, Excel, TXT)
- 🔍 Semantic search dengan AI
- 📊 Dashboard interaktif
- 💬 AI-powered Q&A
- 🎯 Topic clustering

## Cara Penggunaan

1. Upload file berita politik (CSV/Excel/TXT)
2. Klik "Proses Dokumen"
3. Eksplorasi dashboard atau ajukan pertanyaan
